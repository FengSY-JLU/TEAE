# Third-party code and model licensing review

- DTI-UIE: <https://github.com/oucailab/DTIUIE>. Use the official implementation and respect upstream non-commercial licence terms. No third-party baseline weights are included in this source repository.
- HSRUIE: <https://github.com/gemyumeng/HSRUIE>. Use the official implementation and confirm redistribution terms independently.
- Segmentation backbones and their weight files may depend on PyTorch, timm, Transformers, torchvision, and pretrained datasets/weights. Verify individual upstream licence notices and model card terms before hosting binaries.
- The accompanying TEAE inference/assessment source and the original research code may have different licence provenance. Confirm author ownership and any borrowed third-party source obligations before selecting a repository-wide LICENSE.

**The repository intentionally has no default LICENSE until its contributors complete the above review.** This is a publication candidate, not a granted permission to use every artifact commercially.
